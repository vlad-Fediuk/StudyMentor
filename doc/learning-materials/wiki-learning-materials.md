# StudyMentor Learning Materials

## Public folder

Learning materials for student education are stored in this repository folder:

[doc/learning-materials](https://github.com/vlad-Fediuk/StudyMentor/tree/featuer/s-76-implement-authentification/doc/learning-materials)

This folder is intended to be open for all project participants. New `.md` files for student learning can be uploaded there and later used as source documents for the vector database.

## Available materials

1. [OOP: Encapsulation and Abstraction](https://github.com/vlad-Fediuk/StudyMentor/blob/featuer/s-76-implement-authentification/doc/learning-materials/oop-encapsulation-abstraction.md)
2. [QA Engineering: Test Design Techniques and Test Cases](https://github.com/vlad-Fediuk/StudyMentor/blob/featuer/s-76-implement-authentification/doc/learning-materials/qa-test-design-and-test-cases.md)

## How these materials should be used

These documents are written as factual learning sources. They contain definitions, explanations, examples, typical mistakes, practical rules, self-check questions, and short answer blocks.

When the materials are added to a vector database, StudyMentor should use them as trusted context for answering student questions about OOP and QA Engineering.

The assistant should answer according to the facts in these documents and avoid unrelated or random explanations when a student asks about these topics.
